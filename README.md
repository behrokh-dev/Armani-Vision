# Armani Vision 👓

A modern, fully responsive Persian-language eyewear store landing page built with **HTML**, **CSS**, and **Tailwind CSS**. The project focuses on delivering a premium user experience with elegant UI design, smooth interactions, and seamless responsiveness across all devices.

🔗 **Live Demo:** https://behrokh-dev.github.io/Armani-Vision/

## ✨ Features

- 🎨 Modern and luxury-inspired eyewear store design
- 📱 Fully responsive layout for mobile, tablet, and desktop
- 🌍 Persian (RTL) user interface
- ⚡ Fast and lightweight implementation
- 🎭 Smooth animations and interactive UI elements
- 🖼️ Product showcase sections with attractive visual presentation
- 🧩 Component-based structure for easier maintenance
- 🎯 Optimized user experience and accessibility

## 🚀 Getting Started

Clone the repository:

```bash
git clone https://github.com/Behrokh-Dev/Armani-Vision.git
```

Navigate to the project directory:

```bash
cd Armani-Vision
```

Open `index.html` in your browser or run a local development server.
